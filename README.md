# StudyMate AI

Projeto de estudo utilizando RAG (Retrieval-Augmented Generation) para realizar perguntas e respostas baseadas em documentos PDF.

## Sobre

A aplicação permite enviar documentos PDF, processar seus conteúdos e utilizar uma LLM para responder perguntas utilizando as informações encontradas nos documentos.

O objetivo do projeto é estudar conceitos de Inteligência Artificial aplicada ao desenvolvimento de software, como:

- RAG
- LLMs
- Embeddings
- Busca semântica
- Banco vetorial
- Agentes de IA

## Tecnologias

- Python
- FastAPI
- LangChain
- ChromaDB
- LLM compatível com OpenAI API

## Funcionalidades

- Upload de documentos PDF
- Processamento automático dos documentos
- Criação de embeddings
- Armazenamento em banco vetorial
- Busca de informações nos documentos
- Perguntas e respostas utilizando RAG
- Suporte para múltiplos documentos
- Gerenciamento de documentos
